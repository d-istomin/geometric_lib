# **Отчет по лабораторной работе: Git**

**Репозиторий:** [https://github.com/d-istomin/geometric\_lib](https://github.com/d-istomin/geometric_lib)  
 

### **1\. Клонирование репозитория**

git clone https://github.com/smartiqaorg/geometric\_lib  
 cd geometric\_lib

**Вывод терминала:**  
Cloning into 'geometric\_lib'...  
 remote: Enumerating objects: 35, done.  
 remote: Total 35 (delta 0), reused 0 (delta 0), pack-reused 35 (from 1\)  
 Receiving objects: 100% (35/35), 4.80 KiB | 2.40 MiB/s, done.  
 Resolving deltas: 100% (4/4), done.

●      git clone \<url\> — копирует удаленный репозиторий вместе со всей историей веток и коммитов в локальный каталог.  
●      cd \<dir\> — переходит в созданный каталог проекта.

### **2\. Создание ветки и переключение**

git branch new\_features\_558270  
 git checkout new\_features\_558270

**Вывод терминала:**  
Switched to branch 'new\_features\_558270'

●      git branch \<name\> — создает новую ветку с заданным именем.  
●      git checkout \<name\> — переключает рабочее дерево на указанную ветку.

### **3\. Добавление файла rectangle.py**

git add rectangle.py

●      git add \<файл\> — добавляет изменения рабочего файла в область индекса (staging area) для подготовки к коммиту.

### **4\. Фиксация изменений (коммит с прямоугольником)**

git commit \-m "added functions for the rectangle"

**Вывод терминала:**  
\[new\_features\_558270 fde6200\] added functions for the rectangle  
  1 file changed, 5 insertions(+)  
  create mode 100644 rectangle.py

●      git commit — создает снимок проиндексированных изменений в репозитории.  
●      Флаг \-m "\<текст\>" — задает сообщение коммита прямо из терминала без открытия редактора.  
>

●      Флаг \--all — показывает коммиты во всех существующих ветках (локальных и удаленных).

### **9\. Построение графа текущей ветки**

git log \--graph \--oneline \-2

**Вывод терминала:**  
\* de3f18d (HEAD \-\> new\_features\_558270) fixed bag with perimeter of rectangle  
 \* df9076b added functions for the triangle

●      Без флага \--all вывод ограничивается только текущей веткой.  
●      Флаг \-2 (или \-n 2\) — ограничивает глубину истории двумя последними коммитами.  
>  

### **10\. Просмотр изменений по хэшам двух последних коммитов**

git diff df9076b de3f18d

**Вывод терминала:**  
diff \--git a/rectangle.py b/rectangle.py  
 index 7768cf4..f19cc2a 100644  
 \--- a/rectangle.py  
 \+++ b/rectangle.py  
 @@ \-4,2 \+4,2 @@ def area(a, b):  
  def perimeter(a, b):  
 \-	return a \+ b  
 \+	return 2 \* (a \+ b)

●      git diff \<hash1\> \<hash2\> — сравнивает два коммита и показывает построчную разницу (diff) между ними.  
 *(Также для просмотра отдельного коммита использовалась команда git show \<hash\>, выводящая метаданные коммита и его патч).*

### **11\. Удаление ветки без слияния**

git checkout main  
 git branch \-D new\_features\_558270

●      git checkout main — переключает рабочее дерево на ветку main (нельзя удалить ветку, находясь в ней).  
●      git branch — утилита управления ветками.  
●      Флаг \-D (сокращение от \--delete \--force) — принудительно удаляет ветку, даже если в ней есть коммиты, которые еще не были влиты (merged) в основную ветку.
