# Документация Geometric Lib

`geometric_lib` — библиотека геометрических вычислений на языке Python, предоставляющая функции для расчёта площадей ($S$) и периметров ($P$) базовых геометрических фигур: круга, прямоугольника, квадрата и треугольника.

```text
    ├── rectangle.py                               # Функции для прямоугольника
    ├── square.py                                  # Функции для квадрата
    └── triangle.py                                # Функции для треугольника
```

### Математические формулы

| Фигура | Площадь ($S$) | Периметр ($P$) |
| :--- | :--- | :--- |
| **Круг** | $S = \pi r^2$ | $P = 2\pi r$ |
| **Прямоугольник** | $S = a \cdot b$ | $P = 2(a + b)$ |
| **Квадрат** | $S = a^2$ | $P = 4a$ |
| **Треугольник** | $S = \frac{a \cdot h}{2}$ | $P = a + b + c$ |

## Описание функций с примерами вызова

### Круг (`scripts/circle.py`)

Модуль содержит функции для вычисления площади и периметра (длины окружности) круга с использованием константы $\pi$ из стандартного модуля `math`.

#### 1. `area(r)`
Вычисляет площадь круга по его радиусу.
- **Параметры:**
  - `r` (`float | int`): радиус круга.
- **Возвращаемое значение:**
  - `float`: площадь круга.
- **Пример вызова:**
  ```python
  from scripts.circle import area

  radius = 5
  result = area(radius)
  print(f"Площадь круга с радиусом {radius}: {result}")
  # Вывод: Площадь круга с радиусом 5: 78.53981633974483
  ```

#### 2. `perimeter(r)`
Вычисляет длину окружности (периметр) круга по его радиусу.
- **Параметры:**
  - `r` (`float | int`): радиус круга.
- **Возвращаемое значение:**
  - `float`: длина окружности круга.
- **Пример вызова:**
  ```python
  from scripts.circle import perimeter

  radius = 5
  result = perimeter(radius)
  print(f"Длина окружности с радиусом {radius}: {result}")
  # Вывод: Длина окружности с радиусом 5: 31.41592653589793
  ```

### Прямоугольник (`scripts/rectangle.py`)

Модуль содержит функции для вычисления площади и периметра прямоугольника по двум сторонам.

#### 1. `area(a, b)`
Вычисляет площадь прямоугольника по двум смежным сторонам.
- **Параметры:**
  - `a` (`float | int`): длина первой стороны прямоугольника.
  - `b` (`float | int`): длина второй стороны прямоугольника.
- **Возвращаемое значение:**
  - `float | int`: площадь прямоугольника.
- **Пример вызова:**
  ```python
  from scripts.rectangle import area

  a, b = 3, 4
  result = area(a, b)
  print(f"Площадь прямоугольника со сторонами {a} и {b}: {result}")
  # Вывод: Площадь прямоугольника со сторонами 3 и 4: 12
  ```

#### 2. `perimeter(a, b)`
Вычисляет периметр прямоугольника по двум смежным сторонам.
- **Параметры:**
  - `a` (`float | int`): длина первой стороны прямоугольника.
  - `b` (`float | int`): длина второй стороны прямоугольника.
- **Возвращаемое значение:**
  - `float | int`: периметр прямоугольника.
- **Пример вызова:**
  ```python
  from scripts.rectangle import perimeter

  a, b = 3, 4
  result = perimeter(a, b)
  print(f"Периметр прямоугольника со сторонами {a} и {b}: {result}")
  # Вывод: Периметр прямоугольника со сторонами 3 и 4: 14
  ```

### Треугольник (`scripts/triangle.py`)

Модуль содержит функции для вычисления площади треугольника по основанию и высоте, а также периметра по трем сторонам.

#### 1. `area(a, h)`
Вычисляет площадь треугольника по основанию и высоте, опущенной на это основание.
- **Параметры:**
  - `a` (`float | int`): основание (длина стороны) треугольника.
  - `h` (`float | int`): высота треугольника, опущенная на основание `a`.
- **Возвращаемое значение:**
  - `float`: площадь треугольника.
- **Пример вызова:**
  ```python
  from scripts.triangle import area

  base, height = 6, 4
  result = area(base, height)
  print(f"Площадь треугольника с основанием {base} и высотой {height}: {result}")
  # Вывод: Площадь треугольника с основанием 6 и высотой 4: 12.0
  ```

#### 2. `perimeter(a, b, c)`
Вычисляет периметр треугольника по трём его сторонам.
- **Параметры:**
  - `a` (`float | int`): длина первой стороны треугольника.
  - `b` (`float | int`): длина второй стороны треугольника.
  - `c` (`float | int`): длина третьей стороны треугольника.
- **Возвращаемое значение:**
  - `float | int`: периметр треугольника.
- **Пример вызова:**
  ```python
  from scripts.triangle import perimeter

  a, b, c = 3, 4, 5
  result = perimeter(a, b, c)
  print(f"Периметр треугольника со сторонами {a}, {b}, {c}: {result}")
  # Вывод: Периметр треугольника со сторонами 3, 4, 5: 12
  ```
